# SLM-LLM 기반 스키마 매칭 및 설명가능 인공지능을 활용한 데이터 자산 가격 예측 및 가치평가 연구

고려대학교 SW·AI융합대학원 빅데이터융합학과 공학석사 학위논문 (권순률, 지도교수 강성구, 2027년 2월)

석사학위논문 심사위원께서 논문의 전체 흐름을 파악하실 수 있도록 정리한 요약 페이지입니다.

- **요약 페이지**: https://srkwon.github.io/thesis-data-asset-valuation/
- **논문 전문 (최종본, PDF)**: [`paper/thesis.pdf`](paper/thesis.pdf)
- **발표자료**: https://srkwon.github.io/thesis-data-asset-valuation/slides/ (← → 키로 이동, F 전체화면)

## 연구 요약

| 연구 문제 | 장 | 핵심 결과 |
|---|---|---|
| RQ1. SLM-LLM 스키마 매칭은 이질적인 원천 컬럼을 표준 스키마로 얼마나 잘 정규화하는가? | 4장 | SLM Recall@5 0.4003 → LLM 재평가 후 정합률 **0.7946** (LLM 기준값 대비) |
| RQ2. 정형·비정형·표준 스키마 피처를 단계적으로 추가하면 가격 예측 성능은 어떻게 달라지는가? | 5장 | 최종 XGBoost(Step 4) MAE **419,474원**, R² **0.9512** (베이스라인 대비 MAE −46.2%) |
| RQ3. 각 피처는 예측 가격에 어떤 방향·크기로 기여하는가? | 6장 | 상품 설명의 ‘기간’이 최대 기여(평균 \|SHAP\| 1.24), 텍스트가 전체 기여의 81.5% |

분석 대상: 국내 민간 데이터 거래소 데이터 상품 11,028건 중 유료 상품 1,985건, 원천 컬럼 1,519개.
